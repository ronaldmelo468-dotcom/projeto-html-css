🏍️ As Feras de 4 Cilindros
📌 Sobre o projeto

O projeto As Feras de 4 Cilindros é um site desenvolvido em HTML e CSS com o objetivo de apresentar algumas das motos esportivas de quatro cilindros mais conhecidas do mundo.

O site apresenta informações sobre cada motocicleta, suas características, potência, tecnologia e design.

🏁 Motos apresentadas

O projeto contém cinco páginas dedicadas às seguintes motocicletas:

Kawasaki Ninja ZX-10R – Uma superbike conhecida pelo seu desempenho e DNA de competição.
Yamaha YZF-R1 – Uma moto esportiva com tecnologia inspirada nas pistas.
Honda CBR1000RR-R Fireblade – Uma motocicleta que combina engenharia e desempenho.
Suzuki GSX-R1000 – Uma superbike conhecida pela tradição nas competições.
BMW S 1000 RR – Uma moto que combina tecnologia, potência e design moderno.
💻 Tecnologias utilizadas
HTML5 – Estruturação das páginas.
CSS3 – Estilização e organização dos elementos.
Visual Studio Code – Editor utilizado no desenvolvimento.

⚙️ Funcionalidades
Página inicial com apresentação do projeto.
Menu lateral para navegar entre as cinco motocicletas.
Uma página individual para cada moto.
Espaço para adicionar imagens e fotografias.
Botão para retornar à página inicial.
Estilo visual padronizado em todas as páginas.
🚀 Como executar
Baixe ou copie os arquivos do projeto.
Abra a pasta no Visual Studio Code.
Verifique se as pastas HTML, CSS e imagens estão organizadas corretamente.
Abra o arquivo index.html no navegador.
Navegue pelo menu lateral para conhecer as motocicletas.
🎯 Objetivo

O objetivo deste projeto é praticar os conhecimentos de HTML e CSS, desenvolvendo um site com várias páginas, imagens, links de navegação e organização de conteúdo.

As Feras de 4 Cilindros – Potência, Velocidade e Adrenalina! 🏍️

Projeto desenvolvido para fins educacionais.
